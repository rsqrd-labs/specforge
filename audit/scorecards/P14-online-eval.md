| 9 | Variable interpolation safety | **1** | `_build_eval_prompt` (`online_eval.py:966-982`) assembles the final prompt via **chained `.str.replace()` calls**: `.replace("{spec_content}", context).replace("{content}", artifact)`. Because `.replace()` operates on the **already-substituted** string, if the *first* substitution (`context`, the compacted spec/dependency text) itself contains the literal substring `"{content}"` — plausible in a real technical Markdown document, e.g. a JSON-shaped code example, a schema field literally named `content`, or an adversarial payload deliberately crafted to include that token — the **second** `.replace()` call will also match and replace that occurrence, silently splicing the artifact-under-evaluation's text into the middle of what the judge is told is *reference/spec* context. This corrupts the data/task boundary the judge relies on to know what it's grading vs. what it's grading *against*, and does so **without any error, exception, or log** — a silent correctness bug, not a crash. Verified by reading the exact call chain (`online_eval.py:979-982`); no test in the coverage that follows (`eval_batch.py`, backend tests) was found asserting behavior when `spec_content` contains the literal token `{content}`. |

**Top risk (dimension 9):** A real, reproducible correctness bug — not a hypothetical — that silently corrupts the eval judge's prompt whenever graded content contains the literal substring `{content}`, with no error surfaced. Given this feeds a user-visible quality score, a silently-corrupted judge call could produce a materially wrong score with nothing in the system signaling that anything went wrong.

**Verdict:** SHIP-BLOCKER (recommended pending advisor review) for dimension 9 — it is a live, mechanically-triggerable bug (not a security/adversarial scenario) with a trivial, well-known fix (use two single-pass, non-chained substitutions, e.g. via `.format_map` on a dict, or replace both placeholders from the *original* template in one pass with `re.sub` using a callback, or simply reorder to substitute the *longer/rarer* placeholder last against the *original* string rather than the partially-substituted one). Dimension 8's missing injection-safety framing is a HIGH-severity consistency gap on its own.
